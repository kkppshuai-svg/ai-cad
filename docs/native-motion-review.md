# NVIDIA 原生行星机构运动干涉审查

运动干涉现在是联合审查的一部分：NVIDIA 构建 → 单件及装配 USD 回读 → 尺寸复测 → 运动干涉 → 当前修订截图视觉复审。首次生成和二次修改调用同一条通路。`motion-review.json` 与精确 USD 的摘要共同绑定修订，旧版本的运动或视觉通过不能继承。

## 当前覆盖

支持 `planetary-5to1-native-v1` 的直齿行星机构：24T 太阳轮、36T×3 行星轮、96T 内齿圈和带销行星架。内齿圈固定、太阳轮输入、行星架输出；相对输入角速度分别为 `1 / -1/3 / 0 / 1/5`（太阳轮 / 行星轮自转 / 内齿圈 / 行星架）。角速度由当前齿数推导，不从显示文字中猜测。

只接受已知的 Z 向拉伸实体和共轴旋转。新增非对称齿轮特征、倾斜轴线、横向孔或未知运动机构时返回 `unverified` 并阻断，避免套用错误运动规律。

## 几何和速度

[`native_motion_review.py`](../scripts/native_motion_review.py)直接对 NVIDIA 原生 BRep 求水平截面，按照实际 BRep 顶点高度分层，保留齿圈空腔、轴孔和销轴。直线/圆弧边界自适应采样，默认截面弦差阈值 `0.0001 mm`。Shapely/GEOS 只计算截面距离和交集，建模与截面来源均为 NVIDIA；不调用 CadQuery/OpenCascade。

检查使用行星架参考系。该实例输入每转 `18.75°`，相对太阳轮前进一个齿、行星轮后退一个齿、内齿圈相对转动一个齿；整个构形在公共刚体旋转下重复。因此一个啮合周期可覆盖输入 `1800°`、行星架一整圈的碰撞关系。该约简仅在上述齿形对称条件仍成立时使用。

默认检查 301 个状态；采用静态边界空间索引减少逐对齿面距离计算。根据运动速度界和相邻采样时间，扣除两条截面的离散阈值及采样间隔位移，计算 `intervalClearanceLowerEstimateMm`。余量不足会自动细化，最多 2401 个状态；仍不足则返回 `unverified`，不会仅凭采样点无重叠判定通过。

轴向层之间的端面接触也会检查，避免仅做体积求交而漏掉齿轮端面与行星架擦碰。报告区分 `solid_interference` 与 `unintended_surface_contact`。

首次原生实例实测：301 状态、7525 次配对检查、最小采样间隙约 `0.1124 mm`、间隔余量估计约 `0.0801 mm`，耗时约 `42.3 s`。这次记录早于新增端面检查；最终耗时和采样统计以当前修订的报告为准。该数字不是制造公差，也不是通用 CAD 性能基准。

加入端面检查并复用重复截面的空间索引、变换和配对结果后，同一个原生实例复测：301 状态、16555 次含层边界的配对检查、最小采样间隙和间隔余量估计保持一致，约 `26.4 s`。记录保存在本地 `output/native-motion-probe.json`。不同齿宽造成轴向分层变化，耗时会不同。

## 统一决策

报告包含运动规律、覆盖周期、状态数、最小采样间隙、间隔余量估计、最危险配对、碰撞角度、截面重叠面积/体积估计及耗时。碰撞作为 `MOTION_INTERFERENCE` 写入联合问题清单，可定位零件和特征；不可靠或缺失的运动证据写入 `NATIVE_MOTION_REVIEW_UNVERIFIED`。

`pass` 仅表示在受支持机构、截面离散和刚体速度界估计范围内通过。它不构成通用三维接触动力学、严格曲面 Hausdorff 距离证明、弹性变形、背隙动力响应或强度寿命验证。完整交付仍需要新修订视觉审查通过。

独立 NVIDIA 环境需要 `requirements-usd-brep.txt`。回归测试包括正常完整周期、起始无碰撞但运动碰撞、轴向端面接触以及非对称改动拒绝：

```bash
python -m unittest discover -s scripts -p test_native_motion.py -v
```
