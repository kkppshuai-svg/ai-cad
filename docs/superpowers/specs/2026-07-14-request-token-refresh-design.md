# 请求令牌自动刷新设计

## 问题

AI-CAD 服务每次启动都会生成新的请求令牌。已经打开的浏览器页面继续持有旧令牌，后续 POST 请求收到 `403 Invalid request token`，只能人工刷新页面。

## 方案

将前端请求逻辑拆为可测试的 API 客户端。POST 请求遇到且仅遇到 `403` 与 `Invalid request token` 时，请求一次 `/api/status` 获取新令牌，然后用新令牌重放原请求一次。重放仍失败则返回原始错误，不继续循环。

GET 请求、其他 403、网络错误及业务错误均不触发令牌刷新。服务端精确令牌校验保持不变。

## 验证

- 旧令牌的 POST 自动刷新并成功重试。
- 非令牌 403 不重试。
- 刷新后仍失败时总 POST 次数为两次，不无限循环。
- 完整项目测试通过。
