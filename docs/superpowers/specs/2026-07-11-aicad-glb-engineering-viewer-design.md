# AI CAD GLB 工程查看器设计

## 目标

在保留现有 FCStd、STEP、STL 输出和视觉审查能力的前提下，将手写 WebGL + STL 预览升级为基于 Three.js + GLB 的本地工程查看器。首阶段重点解决零件识别与工程操作，而非仅提升材质观感。

## 架构

CadQuery 2.7 已支持 `Assembly.save(..., exportType="GLTF")`。构建脚本在生成装配 STEP/STL 时同步生成 `assembly.glb`，GLB 保留装配中的独立零件节点、变换与颜色。服务端把 `glbPath/glbUrl` 加入装配结果，同时继续提供原有 STL 字段作为兼容下载和降级预览。

浏览器使用本地安装的 Three.js 模块、`GLTFLoader` 和 `OrbitControls`。查看器优先加载 GLB；若旧任务没有 GLB 或加载失败，则回退现有 STL 数据路径并显示降级状态。Three.js 场景、相机、选择、可见性和截图能力封装在独立模块，业务页面只负责传入模型 URL 与零件元数据。

## 查看器功能

- 轨道旋转、平移、缩放和自动适配模型。
- 3D 透视、前视、顶视、侧视和复位。
- 实体、带边线和线框显示模式。
- 点击零件进行选择，并显示冷蓝色轮廓/高亮。
- 装配树和 3D 选择双向联动。
- 隐藏选中、隔离选中、显示全部。
- 将非选中零件设为透明，便于观察内部结构。
- 装配模式加载 GLB；单零件模式仍可加载该零件 STL，直到后续需要独立零件 GLB。
- Canvas 截图继续供视觉审查的 3D、前、顶、侧视图使用。

首阶段不加入尺寸测量、剖切面、标注和爆炸动画，但模块边界要允许后续增加这些工具。

## 零件身份映射

GLB 节点名来自 CadQuery Assembly 的零件 ID。加载后对节点名进行安全标准化，并与装配结果中的 `parts[].id` 建立映射。若导出器增加层级包装节点，则查看器遍历所有 Mesh，将最接近零件 ID 的祖先节点作为选择单元。

每个可选单元保存原始材质、可见性和透明度，避免重复选择或模式切换后丢失状态。装配树卡片继续使用现有 `data-part-id`/点击逻辑，并新增选择、可见和隔离状态样式。

## UI 变化

保留现有视角按钮，在视口工具栏增加：

- 隐藏选中
- 隔离选中
- 显示全部
- 透明查看

`viewerStats` 显示当前文件类型、三角面数量、零件数量和选中零件。零件列表的活动项既代表编辑器当前零件，也代表查看器当前选择；用户从 3D 点选零件时同步更新编辑器内容。

## 文件与依赖

- `scripts/cadquery_build.py`：生成装配 GLB 并在构建摘要中返回路径。
- `server.js`：持久化并公开 `glbUrl`。
- `public/cad-viewer.js`：Three.js 场景、加载、选择、显示模式、视角和截图接口。
- `public/app.js`：把现有 UI 状态连接到查看器模块。
- `public/index.html`：增加工程查看器工具按钮。
- `public/styles.css`：增加选择状态和工具按钮样式。
- `package.json` / `package-lock.json`：加入固定版本 Three.js 依赖。
- `server.js` 静态资源路由：只公开 Three.js 所需模块，不暴露整个 `node_modules`。

## 错误处理

- GLB 生成失败时不阻断 STEP/STL 主构建；摘要记录警告并保留 STL 降级预览。
- GLB 加载失败时前端自动尝试装配 STL，并在状态栏标注“STL 兼容模式”。
- 工程操作在未选中零件时保持禁用或给出明确状态，不抛出运行时错误。
- 加载新模型前释放旧几何、材质、纹理和对象 URL，避免连续生成造成显存泄漏。

## 测试与验证

- Python 测试验证 GLB 输出路径、文件存在及构建摘要字段。
- Node 测试验证服务端公开 `glbUrl` 且原 STL 字段仍存在。
- UI 静态测试验证 Three.js 模块、工程工具按钮和选择联动接口。
- 运行完整 `npm run check`，确保现有预览、视图和视觉审查测试继续通过。
- 用真实多零件装配构建 GLB，验证节点数、零件映射、点击选择、隐藏、隔离、透明、视图切换与截图。
- 在桌面和移动宽度进行渲染审查，确认工具栏可换行且视口可操作。

## 兼容性边界

不删除 STL 生成和下载，不改变现有 API 路径，不引入云端查看服务，不在浏览器解析 STEP，也不改变 CadQuery 特征 JSON、FreeCAD 桥接或评分流程。
