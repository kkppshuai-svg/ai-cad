# AI CAD 深色精密工业 UI 设计

## 目标

将现有 AI CAD 网页从展示型玻璃卡片界面升级为紧凑、成熟的专业 CAD 工作台。升级只涉及视觉层级、布局密度、排版和响应式表现，不增加、删除或改变任何现有业务功能。

## 设计原则

- 保持现有工作流：对话建模、联网搜索、JSON 编辑、3D 预览、视角切换、文件导出、视觉审查、零件与装配关系、日志和人工评分均原样保留。
- 保持 JavaScript 依赖的 DOM ID 和事件语义，避免 UI 改造影响现有交互。
- 让 3D 视口成为视觉中心，界面装饰退居次要层级。
- 使用深枪灰、冷蓝状态色、精密细边框和紧凑间距，形成专业工程软件气质。
- 减少大圆角、胶囊按钮、强渐变、毛玻璃和大面积装饰性标题。

## 页面架构

### 顶部应用栏

现有 hero 区压缩为紧凑应用栏。左侧显示产品名称和一句简短工作流说明，右侧保留引擎连接状态。应用栏高度控制在约 64–84px，不再使用超大衬线标题。

状态区域采用在线指示点、等宽技术信息和低对比辅助文字。现有 `engineStatus` 内容及连接逻辑保持不变。

### 主工作区

桌面端继续采用三栏布局：

1. 左栏为建模对话、搜索、附件和流程说明。
2. 中栏为当前零件的 CadQuery 特征 JSON 与预览/导出操作。
3. 右栏为大型 3D 视口、下载项、视觉审查、零件列表、装配关系和日志。

列宽采用紧凑专业比例：左栏约 320–360px，中栏约 300–340px，右栏占据其余空间并设置合理最小宽度。较窄屏幕下先改为双栏，再在移动端单栏堆叠，不隐藏功能。

固定在右侧的人工评分面板保留，但改为工程检查器风格。主内容为其预留空间，避免遮挡视口和操作按钮。

## 视觉系统

### 色彩

- 页面底色：接近黑色的冷枪灰，而非纯黑。
- 面板底色：分为基础层、抬升层和输入层三个灰度层级。
- 主文字：冷白色；辅助文字：低饱和蓝灰。
- 主强调色：克制的工程冷蓝，用于主要操作、焦点和活动状态。
- 成功、警告、失败：分别使用低饱和绿、琥珀黄和红色，只在状态信息中出现。
- 移除当前暖橙与青绿色的大面积环境光渐变。

### 字体与排版

- 界面字体使用可靠的系统无衬线字体栈，中文优先匹配系统 UI 字体。
- JSON、作业 ID、状态值和技术数据使用等宽字体栈。
- 页面标题控制在 18–22px；面板标题约 12–13px，并使用适度字距表达工具面板层级。
- 正文与控件以 12–14px 为主，保证紧凑但可读。

### 形状与层级

- 面板圆角统一为 8–10px，输入框和按钮为 5–7px。
- 使用 1px 冷灰边框区分区域，避免厚重阴影。
- 仅对浮动评分面板使用轻微阴影，其余面板主要依靠底色和边框分层。
- 取消大面积 `backdrop-filter`，提升清晰度并减少渲染负担。

## 组件设计

### 按钮

主要操作使用冷蓝实底；次要操作使用灰色底与细边框；危险或失败状态只在确有语义时使用红色。按钮统一为小圆角矩形，不再使用全胶囊造型。

悬停效果以边框、底色和轻微亮度变化为主，不使用明显位移。禁用状态降低对比度并保留清晰轮廓。

### 输入与编辑器

输入框采用深色凹陷层，焦点显示细冷蓝描边。聊天输入保持可调整高度；JSON 编辑器继续占满中栏剩余高度，并强化等宽字体、行距和编辑器边界。

### 3D 视口

视口使用更深的中性背景和细网格/工程底板质感，但不干扰模型观察。视图状态位于左上角，视角与线框工具组织为右上或底部紧凑工具条。现有按钮 ID、功能和顺序语义保持不变。

空状态使用简洁十字准星或线框立方体式视觉提示，不引入外部图片资产。

### 下载与数据区

下载链接和仿真/视觉审查操作改为可换行的工具按钮组。零件、装配关系、视觉审查和日志使用统一的工程数据面板样式，以标题栏、分隔线和状态色建立层级。

### 对话与评分

对话气泡减少圆润感，用户消息以冷蓝暗色区分，系统消息使用中性灰。图片附件、搜索结果和流程说明使用相同的子面板规则。

评分面板保留 0/50/100 三种选择及所有提交逻辑。选项采用检查卡样式，选择状态使用相应状态色和细描边，而非高饱和大色块。

## 交互与数据流

本次不改变数据流。`public/app.js` 中的 API 请求、事件流、LocalStorage、WebGL 预览、文件下载和评分提交逻辑保持不变。若为视觉状态需要增加 class 或 `aria-*` 属性，只能作为现有状态的呈现层，不创建新的业务状态。

## 响应式行为

- 宽屏：三栏工作台，右侧固定评分检查器。
- 中等屏幕：对话与编辑器组成较窄控制区，视口仍优先获得空间；评分面板可进入正常文档流或缩窄。
- 小屏：所有面板单栏排列，评分面板取消 fixed，视口维持可操作的最小高度，下载按钮和工具栏自动换行。
- 所有断点均保留完整功能，不通过 `display: none` 删除核心操作。

## 可访问性与兼容性

- 保持原生表单标签和键盘可操作性。
- 焦点态不能仅依靠颜色，需同时有轮廓或边框变化。
- 文字和主要控件满足深色界面的清晰对比度。
- 不依赖外部字体、图标库或构建工具，继续沿用当前原生 HTML/CSS/JS 架构。
- 尊重 `prefers-reduced-motion`，禁用非必要过渡。

## 验证标准

- 所有现有 DOM ID 仍存在且唯一。
- 现有 UI、复制文本、视图和视觉审查相关测试通过。
- 页面加载后无 JavaScript 控制台错误。
- 桌面宽屏、常见笔记本宽度和移动宽度下无关键内容遮挡或横向溢出。
- 对话、图片附件、搜索、编辑、预览、视角切换、下载、视觉审查和评分操作均可到达。
- 视觉结果不再呈现大标题、暖色渐变、毛玻璃卡片和胶囊按钮主导的展示页观感。

## 范围边界

本次不重写 WebGL 查看器、不修改服务端接口、不增加图标依赖、不重新设计业务流程，也不处理与 UI 升级无关的代码重构或现有功能缺陷。
