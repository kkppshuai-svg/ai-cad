# Dimension 节点兼容与提前校验设计

## 问题

规划器可能把尺寸组输出为 `dimension` 节点，但只提供 `horizontalPitch`、`verticalPitch` 等命名数值，没有标准 `value`。当前服务器先保存原计划，直到构建阶段才运行参数化规范化，因此用户看到晚期构建失败。

## 修复

参数化规范化支持安全的旧式尺寸组：缺少 `value` 时，收集 `params` 顶层有限数值；只有一个数值或所有数值相同时推导为 `value`。不同数值、没有数值或数组坐标不参与推导，继续明确报错。

规划器完整计划在验证后立即调用 `normalizeParametricPlan`，保存和构建使用同一份规范化计划，使 schema 错误在进入对话状态和构建队列前暴露。

提示契约明确每个 `dimension` 必须使用 `params.name` 与 `params.value`；水平和垂直尺寸不同则拆成独立节点。

- 当前步进电机孔距尺寸组推导为 47.14。
- 冲突尺寸不推导并报错。
- 规范化保持幂等。
- 完整测试通过。
